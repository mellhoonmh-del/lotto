# 🎱 Streamlit Lotto Number Generator

실제 로또 공의 색상과 규칙을 반영한 인터랙티브한 **로또 번호 생성기** 웹 애플리케이션입니다. Python과 [Streamlit](https://streamlit.io/)을 기반으로 제작되었습니다.

## ✨ 주요 기능
- **중복 없는 번호 추출**: 1부터 45 사이의 숫자 중 무작위로 6개의 번호를 뽑아 오름차순으로 정렬합니다.
- **실제 로또 공 색상 적용**:
  - `1 ~ 10`: 🟡 노란색
  - `11 ~ 20`: 🔵 파란색
  - `21 ~ 30`: 🔴 빨간색
  - `31 ~ 40`: ⚫ 회색
  - `41 ~ 45`: 🟢 초록색
- **최대 5세트 히스토리 유지**: 버튼을 계속 누르면 새로운 번호가 상단에 추가되며, 6개 세트부터는 가장 오래된 세트가 자동으로 삭제됩니다.

## 📁 파일 구성
- `app.py`: 스트림릿 메인 애플리케이션 코드
- `requirements.txt`: 프로젝트 의존성 패키지 목록
- `README.md`: 프로젝트 설명서
